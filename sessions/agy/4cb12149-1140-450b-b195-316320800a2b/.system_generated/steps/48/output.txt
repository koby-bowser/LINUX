The search for ""https://mcp.excalidraw.com" config json" returned the following summary:
To configure an MCP client for Excalidraw, the exact JSON configuration depends on whether you are using the **Excalidraw+** (official workspace) MCP or the **open-source** MCP server[1][2][3].

### 1. Excalidraw+ MCP (Official)
If you are using Excalidraw+ with an API key, use the following configuration[2][3]. You must replace `<API_KEY>` with your actual API key from your Excalidraw+ workspace settings[4][3].

**Configuration JSON:**
```json
{
  "mcpServers": {
    "excalidraw": {
      "type": "http",
      "url": "https://api.excalidraw.com/api/v1/mcp",
      "headers": {
        "Authorization": "Bearer <API_KEY>"
      }
    }
  }
}
```
*This configuration is commonly used in `claude_desktop_config.json`, Cursor MCP settings, or `.vscode/mcp.json`[3].*

---

### 2. Open-Source / Local MCP Servers
If you are using the open-source community versions (such as `excalidraw-mcp` or `mcp-excalidraw`), the configuration typically points to a local process or a hosted URL[5][6][7].

*   **For local execution (Node.js):**
    ```json
    {
      "mcpServers": {
        "excalidraw": {
          "command": "node",
          "args": ["/path/to/your/excalidraw-mcp/dist/index.js"]
        }
      }
    }
    ```

*   **For the hosted remote server:**
    Some versions provide a hosted endpoint (e.g., `https://excalidraw-mcp-app.vercel.app/mcp`) which may not require an API key[6][8].

### How to Apply
*   **Claude Desktop:** Add the JSON block above to your `claude_desktop_config.json` file (found in `~/Library/Application Support/Claude/` on macOS or `%APPDATA%\Claude\` on Windows).
*   **Cursor / Other IDEs:** Navigate to the MCP settings menu in the IDE's configuration and add the server using the JSON structure appropriate for that client[3].

**Note:** Always ensure your MCP client supports **Streamable HTTP** if you are connecting to the Excalidraw+ API[4][3].
