The search for ""mcp-excalidraw-server" "Claude Desktop"" returned the following summary:
`mcp-excalidraw-server` is an **MCP (Model Context Protocol) server** designed to integrate Excalidraw's diagramming capabilities directly into AI agents, such as those running in **Claude Desktop**, Cursor, or other MCP-compatible clients[1][2][3].

### What it does
Unlike basic integrations that might only generate a static image, `mcp-excalidraw-server` provides a **persistent, interactive workbench** for AI agents[4][5][6]. It allows Claude to[1][6]:
*   **Create and Modify:** Programmatically create, edit, update, or delete elements on an Excalidraw canvas[3][5].
*   **Persistent Workflow:** Maintains the canvas state, allowing for iterative refinement of diagrams rather than one-off generations[7][6].
*   **Advanced Control:** Offers tools for layout management, element-level control, screenshotting (so the AI can "see" what it has drawn), and file export[1][3][5].

### How to use it with Claude Desktop
To use it with Claude Desktop, you typically configure the server in your `claude_desktop_config.json` file[8][9].

1.  **Configuration:** You add the server to your configuration file, pointing to the local installation of the MCP server[8][9]. A typical configuration entry looks like this:
    ```json
    "mcpServers": {
      "excalidraw": {
        "command": "node",
        "args": ["/absolute/path/to/your/excalidraw-mcp/dist/index.js"]
      }
    }
    ```
2.  **Usage:** Once configured and Claude Desktop is restarted, Claude will have access to the Excalidraw tools[9][10]. You can then prompt Claude in natural language to "create an architecture diagram," "visualize this code," or "draw a flowchart," and it will use the MCP tools to interact with the canvas[2][11][10].

### Important Distinction
There are different versions of Excalidraw MCP servers available:
*   **`mcp-excalidraw-server` (e.g., by yctimlin):** This is the version often cited for power users and coding agents, focusing on persistent, multi-tool, agentic workflows[1][7][6].
*   **Official/Other versions:** There are other implementations (including an official Excalidraw+ MCP) that may offer different features, such as simpler "one-shot" diagram generation or integration with Excalidraw's cloud services[12][13][6].

If you are looking for a robust, local-first experience where an AI agent can "work" alongside you on a diagram, the community-maintained `mcp-excalidraw` packages are generally the recommended path[1][7].
