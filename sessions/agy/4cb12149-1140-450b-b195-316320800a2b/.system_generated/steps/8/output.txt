The **draw.io MCP (Model Context Protocol) server** is an integration that allows AI assistants (such as Claude Desktop, Cursor, or VS Code) to programmatically create, manage, and edit diagrams in the `.drawio` format[1][2][3].

By using this protocol, you can instruct an AI to generate flowcharts, architectural diagrams, or system designs from natural language prompts, CSV data, or Mermaid.js code, rather than drawing them manually[4][5][6].

### Key Features
*   **AI-Driven Creation:** Automates the generation of diagrams from structured text or descriptions[7][8].
*   **Seamless Editing:** Diagrams generated by the AI can be opened directly in the draw.io editor for further refinement[1][9].
*   **Flexible Integration:** It supports various workflows, including inline previews in chat interfaces and direct integration into code editors like VS Code[10][9][6].
*   **Format Support:** Handles standard `.drawio` XML files, as well as CSV and Mermaid.js formats[4][8].

### Common Ways to Use It
1.  **MCP App Server:** Renders diagram previews directly within compatible AI chat interfaces (like Claude.ai) using interactive iframes[10][9].
2.  **MCP Tool Server:** An installable package (often via `npx`) that allows your AI client to generate files and open them in your browser-based draw.io editor[9][6].
3.  **VS Code / Cursor Integration:** By configuring the MCP server in your IDE, you can generate and view diagrams directly within your development environment[11][6][12].

For setup, you typically add the server configuration (e.g., using `npx @drawio/mcp`) to your MCP client’s configuration file[9][6]. Documentation and repository links can be found on the official [draw.io GitHub](https://github.com/jgraph/drawio-mcp) or via the [draw.io website](https://www.drawio.com)[10][9].
