The search for ""excalidraw" "mcp" github" returned the following summary:
The integration of **Excalidraw** with the **Model Context Protocol (MCP)** allows AI agents (like Claude Desktop, Cursor, or other MCP-compatible clients) to generate, edit, and interact with hand-drawn-style diagrams directly within an AI chat interface[1][2][3].

### Key Projects & Repositories
*   **[excalidraw/excalidraw-mcp](https://github.com/excalidraw/excalidraw-mcp)**: The official MCP server implementation. It is designed for "prompt-to-diagram" generation, allowing the AI to stream diagrams directly into your conversation[4][1].
*   **[yctimlin/mcp_excalidraw](https://github.com/yctimlin/mcp_excalidraw)**: A community project that functions as a workbench for coding agents. Unlike the official version, it supports persistent, local canvases with granular element-level CRUD (Create, Read, Update, Delete) operations and real-time sync[4][1].
*   **[bassimeledath/excalidraw-render-mcp](https://github.com/bassimeledath/excalidraw-render-mcp)**: A headless renderer that allows MCP clients to generate diagrams as PNG or SVG files locally using a headless Chromium browser[5].
*   **[BV-Venky/excalidraw-architect-mcp](https://github.com/BV-Venky/excalidraw-architect-mcp)**: Focuses on architectural diagramming, where an AI describes the structure and the MCP server handles layout and styling[6][7].

### How It Works
*   **Interactive Interface:** MCP apps can render an interactive Excalidraw canvas inside the chat, allowing you to view and edit the diagram without switching tabs[2][8].
*   **Workflow Integration:** By connecting Excalidraw to your AI agent via MCP, you can move from architectural brainstorming to visual representation without leaving your development environment (like VS Code or Cursor)[9][10].
*   **Programmatic Control:** Advanced implementations allow AI to do more than just "draw" a static image; they can manipulate specific elements, align components, and manage the scene programmatically[4][1].

If you are looking to get started, the **[official repository](https://github.com/excalidraw/excalidraw-mcp)** is the standard starting point for most users[11][3]. For more complex engineering workflows involving persistent files and granular control, community-maintained repositories like `mcp_excalidraw` are often preferred[4][1].
