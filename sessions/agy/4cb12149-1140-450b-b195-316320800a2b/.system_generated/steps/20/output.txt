The **excalidraw/excalidraw-mcp** repository provides an official Model Context Protocol (MCP) server that allows AI assistants (like Claude Desktop) to create and edit diagrams directly within your workflow using Excalidraw[1][2][3].

### Key Features
*   **AI-Driven Diagramming:** Enables you to use natural language prompts to generate hand-drawn style diagrams (e.g., architecture diagrams, flowcharts, mind maps)[4][5][3].
*   **Interactive Editing:** Supports viewport camera control, full-screen editing, and the ability to export diagrams as PNG, SVG, or JSON[5][6][7].
*   **Workflow Integration:** Allows AI agents to "see" and iterate on drawings, helping move diagramming from a post-hoc documentation task to an active part of the design and coding loop[8][9].

### Setup Options
You can integrate Excalidraw into your MCP-compatible environment using one of the following methods:

#### 1. Remote Server (Easiest)
You can point your MCP client to the hosted endpoint[5][10].
*   **Endpoint:** `https://mcp.excalidraw.com` (or `https://excalidraw-mcp-app.vercel.app/mcp`)[1][11][10]

#### 2. Local Installation
For full control, you can run the server locally[1][5]:
1.  **Clone the repository:** `git clone https://github.com/excalidraw/excalidraw-mcp.git`[1][5]
2.  **Build:** Run `pnpm install && pnpm run build`[1][5].
3.  **Configure:** Add the server to your MCP configuration file (e.g., `claude_desktop_config.json` for Claude Desktop)[1][10]:
    ```json
    {
      "mcpServers": {
        "excalidraw": {
          "command": "node",
          "args": ["/path/to/excalidraw-mcp/dist/index.js", "--stdio"]
        }
      }
    }
    ```

### Excalidraw+ MCP
In addition to the open-source project, **Excalidraw+** offers a separate MCP integration currently in public beta[12][13]. It is designed for Excalidraw Plus workspace users and uses a different endpoint:
*   **Endpoint:** `https://api.excalidraw.com/api/v1/mcp`[12][14]
*   **Authentication:** Requires an API key from your Excalidraw Plus workspace, sent via an `Authorization: Bearer <API_KEY>` header[12][14].
