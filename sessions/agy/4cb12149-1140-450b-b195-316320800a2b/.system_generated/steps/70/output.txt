The search for ""mcp-excalidraw-server" "Antigravity"" returned the following summary:
`mcp-excalidraw-server` is a tool that provides AI agents with a persistent, programmatic interface to interact with an **Excalidraw** canvas[1][2]. It allows agents to create, refine, and export diagrams directly within their development workflow[1][3].

**Antigravity** (Google’s agent-first IDE) is one of the AI clients that supports this server[4][5].

### Key Features of `mcp-excalidraw-server`
*   **Programmatic Control:** Unlike simple "prompt-to-diagram" tools, this server provides 26 tools for element-level manipulation (CRUD operations), including aligning, grouping, and distributing elements[6][2].
*   **Stateful Canvas:** It maintains a persistent canvas that AI agents can "see" via screenshots and "draw" on iteratively to fix layouts or update details[1][2].
*   **Integration:** It supports multiple interfaces, including:
    *   **Agent Skill + CLI:** Recommended for coding agents (e.g., Claude Code, Cursor, Antigravity) for zero-config setups[1][7].
    *   **MCP Server:** Exposes tools over `stdio` for any Model Context Protocol-compliant client[1][2].
    *   **REST API:** Available for custom frameworks or LangChain[1][8].

### Usage with Antigravity
Antigravity, being an agent-first IDE, treats MCP servers as integral tools for its workflows[5]. By connecting `mcp-excalidraw-server` to Antigravity, developers can ask the agent to "draw the architecture of this service," and the agent will produce an editable Excalidraw diagram, iterate on it based on your feedback, and save the resulting file directly into the repository[7][5].

**Configuration:**
To use it in Antigravity, you typically add the server to your MCP configuration file (e.g., `mcp_config.json`) or via the IDE's settings menu under "Installed MCP Servers"[9][10]. The command is generally `npx -y mcp-excalidraw-server`[7][11].
