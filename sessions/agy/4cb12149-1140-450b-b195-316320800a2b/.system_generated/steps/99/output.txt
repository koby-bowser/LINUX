The GitHub repository `yctimlin/mcp_excalidraw` provides an MCP (Model Context Protocol) server and agent skill designed to allow AI agents to interact with Excalidraw, enabling them to programmatically create, edit, and export diagrams with real-time canvas synchronization[1][2].

### Configuration for `mcpServers`
To use this MCP server with clients like Claude Desktop or Cursor, you need to add the appropriate configuration to your MCP configuration file (e.g., `claude_desktop_config.json` or `.cursor/mcp.json`)[3][4][5].

While configuration can vary based on whether you are running it locally or via `npx`, here is the standard format often referenced for this repository[3][4][5]:

```json
{
  "mcpServers": {
    "mcp_excalidraw": {
      "command": "npx",
      "args": ["-y", "excalidraw-mcp"]
    }
  }
}
```

**Notes on Configuration:**
*   **Local Paths:** If you have cloned the repository and are running it from a local directory, you should point to the compiled `index.js` file[5][6]:
    ```json
    {
      "mcpServers": {
        "excalidraw": {
          "command": "node",
          "args": ["/absolute/path/to/mcp_excalidraw/dist/index.js"]
        }
      }
    }
    ```
*   **Environment Variables:** Depending on your setup, you may need to specify environment variables like `EXPRESS_SERVER_URL` to point to the canvas server[4][5].

For the most accurate instructions, please check the **README.md** file directly in the [yctimlin/mcp_excalidraw GitHub repository](https://github.com/yctimlin/mcp_excalidraw)[7], as command arguments or server names can sometimes change.
