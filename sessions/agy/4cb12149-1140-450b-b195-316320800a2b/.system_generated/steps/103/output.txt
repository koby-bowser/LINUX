The search for ""mcp-excalidraw-server" "mcp" command args" returned the following summary:
To configure the `mcp-excalidraw-server` (often referenced in the context of the **yctimlin/mcp_excalidraw** implementation), you typically define it as an MCP server within your AI client's configuration file (e.g., `claude_desktop_config.json` or `.cursor/mcp.json`)[1].

### **Typical Configuration**
Most users integrate this server using `npx` to ensure it uses the latest version without needing a manual local build[1].

#### **Claude Desktop / Cursor Configuration**
Add the following to your MCP configuration file:

```json
{
  "mcpServers": {
    "excalidraw": {
      "command": "npx",
      "args": ["-y", "mcp-excalidraw-server"]
    }
  }
}
```

### **Common Command Line Arguments & Options**
If you are running the server directly via the CLI or need to pass specific configurations, here is the standard breakdown:

*   **`npx -y mcp-excalidraw-server`**: The primary command to execute the server[2][3].
*   **Environment Variables**: These are often used to configure the server's behavior, particularly for canvas synchronization[4]:
    *   `EXPRESS_SERVER_URL`: Sets the URL for the local canvas server (e.g., `http://localhost:3000`)[4][5].
    *   `ENABLE_CANVAS_SYNC`: Set to `true` to enable real-time synchronization between the AI agent and the canvas[4][5].
*   **Debug/Help Options**:
    *   `-d`, `--debug`: Enables debug logging[6].
    *   `-?`, `--help`: Shows the help message[6].
    *   `--yes`: Often used with commands like `clear` to skip confirmation prompts[7].

### **Important Notes**
*   **Local vs. Remote**: There are multiple Excalidraw MCP implementations. The setup above is for the common local Node.js-based server[1]. If you are using the official remote version or Excalidraw+, you may need to point to a URL (e.g., `https://api.excalidraw.com/api/v1/mcp`) and provide an API key via headers[8][9][10].
*   **Absolute Paths**: If you have cloned the repository locally and are running from the source instead of `npx`, your `args` should point to the absolute path of the compiled file, typically:
    `"args": ["/absolute/path/to/mcp_excalidraw/dist/index.js"]`[1].
