`netbox.authentication.LDAPBackend` is the standard class used to enable LDAP authentication in NetBox[1][2]. When configuring NetBox for LDAP, it is crucial to use the exact case-sensitive string `'netbox.authentication.LDAPBackend'` in your `configuration.py` file, as using lowercase (`LDAPbackend`) will cause errors[3].

### Key Configuration Steps
*   **Enable Remote Auth:** In `configuration.py`, set `REMOTE_AUTH_ENABLED = True` and `REMOTE_AUTH_BACKEND = 'netbox.authentication.LDAPBackend'`[1][2].
*   **Install Dependencies:** You must install `django-auth-ldap` within your NetBox Python virtual environment[4]. It is recommended to add this to `local_requirements.txt` so it persists through upgrades[4].
*   **Create `ldap_config.py`:** This file must be created in the same directory as your `configuration.py` to house your LDAP-specific settings (e.g., `AUTH_LDAP_SERVER_URI`, `AUTH_LDAP_BIND_DN`)[4][5].
*   **Common Pitfalls:**
    *   **Case Sensitivity:** Ensure it is `LDAPBackend`, not `LDAPbackend`[3].
    *   **Environment:** If using Docker, ensure the LDAP requirements are properly included in your image or volume setup[6][7].
    *   **Permissions/Logging:** If authentication fails, check the NetBox logs[1]. Ensure the `ldap_config.py` file is readable by the user running the NetBox service[1].

For detailed documentation and example configurations, you can refer to the official [NetBox documentation on Authentication](https://netboxlabs.com/docs/netbox/en/stable/configuration/authentication/) or search the [netbox-community GitHub](https://github.com/netbox-community/netbox) for issues related to LDAP configuration if you encounter specific errors[1][2].
