To configure LDAP authentication in NetBox, you must install the `django-auth-ldap` package and create a `ldap_config.py` file to define your LDAP settings[1][2][3].

### 1. Installation
First, ensure the `django-auth-ldap` library is installed in your NetBox virtual environment[1][3]:
```bash
source /opt/netbox/venv/bin/activate
pip install django-auth-ldap
# Recommended: add it to local_requirements.txt to persist across upgrades
echo 'django-auth-ldap' >> /opt/netbox/local_requirements.txt
```

### 2. Enable the Backend
In your `configuration.py` file, set the authentication backend to use LDAP[1][2]:
```python
REMOTE_AUTH_BACKEND = 'netbox.authentication.LDAPBackend'
```

### 3. Create `ldap_config.py`
Create a file named `ldap_config.py` in the same directory as your `configuration.py` (typically `/opt/netbox/netbox/netbox/` for Git/archive installations or `/opt/netbox/conf/` for Python packages)[1][3]. 

Below is a template for the configuration[4][5][6]:

```python
import ldap
from django_auth_ldap.config import LDAPSearch

# Server URI
AUTH_LDAP_SERVER_URI = "ldaps://ldap.example.com:636"

# Bind settings (if your LDAP server requires authentication to search)
AUTH_LDAP_BIND_DN = "CN=netbox_svc,OU=Users,DC=example,DC=com"
AUTH_LDAP_BIND_PASSWORD = "your_password"

# User search configuration
AUTH_LDAP_USER_SEARCH = LDAPSearch(
    "OU=Users,DC=example,DC=com",
    ldap.SCOPE_SUBTREE,
    "(sAMAccountName=%(user)s)"
)

# Attribute mapping
AUTH_LDAP_USER_ATTR_MAP = {
    "first_name": "givenName",
    "last_name": "sn",
    "email": "mail"
}

# Optional: Connection options (e.g., for Active Directory)
AUTH_LDAP_CONNECTION_OPTIONS = {
    ldap.OPT_REFERRALS: 0
}

# Optional: Ignore certificate errors (for self-signed certs)
LDAP_IGNORE_CERT_ERRORS = True
```

### 4. Troubleshooting
*   **Permissions:** If you are using a Python package installation, ensure the `ldap_config.py` file is readable by the NetBox service user (e.g., `chown root:netbox /opt/netbox/conf/ldap_config.py` and `chmod 640`)[1][3].
*   **Logging:** If you encounter issues, you can debug by adding a `LOGGING` configuration to your main `configuration.py` to output LDAP events to a file[7]:
    ```python
    LOGGING = {
        'version': 1,
        'disable_existing_loggers': False,
        'handlers': {
            'netbox_auth_log': {
                'level': 'DEBUG',
                'class': 'logging.handlers.RotatingFileHandler',
                'filename': '/opt/netbox/netbox/logs/django-ldap-debug.log',
            },
        },
        'loggers': {
            'django_auth_ldap': {
                'handlers': ['netbox_auth_log'],
                'level': 'DEBUG',
            },
        },
    }
    ```
*   **Restart:** Always restart the NetBox service (`systemctl restart netbox`) after making changes to either `configuration.py` or `ldap_config.py`[7].
